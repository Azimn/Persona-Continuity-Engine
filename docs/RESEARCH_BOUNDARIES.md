# Research claims, provenance and implementation boundaries

**Evidence ladder:** a source records what an author published; a protocol records the test design; a complete run with raw outputs records behavior; blinded independent replication supports a bounded empirical effect. None establishes consciousness, continuity of subjective experience or a persistent persona in frozen model weights.

**No circular validation:** Attractomancy's methods and results are external experimental inputs to PCE. A PCE outcome cannot retroactively validate Attractomancy's Le Refuge hypothesis. PCE synthetic fixtures cannot be used as Pretorius's independent held-out benchmark. The Doctor Lives cannot be benchmarked on its own training/evidence data and then called generalized.

**Negative results:** publish matched baselines, failures, denial/abstention costs, missing cases and decoder-only explanations. Never drop an arm because it scores worse. A local model saying something character-like is not evidence of source fidelity.

**Authority:** consumer systems own their lives and histories. PCE has no authority to make memories, rewrite relationship trust, infer real observations, or admit synthesized events. The generated representation is a disposable projection with versioned source links.

**Security and privacy:** synthetic examples only by default; real dialogue requires consent, redaction, and recipient approval. Do not include student records, private Calibos/Kiki memories, model keys or user secrets. Original Le Refuge/Attractomancy materials have independent rights constraints; PCE must never copy them by assumption.

**Licensing:** no repository-wide license has yet been chosen. GitHub visibility alone is not permission to reuse third-party code. No existing research code is copied into PCE as part of v0.1.

**Reproducibility:** tests run offline and do not fetch models, external sources or third-party data. A model trial must be opt-in and identify model, parameters, full input, environment and output artifact. When a change affects interpretation, append a dated changelog and evidence note rather than revising past results in place.
