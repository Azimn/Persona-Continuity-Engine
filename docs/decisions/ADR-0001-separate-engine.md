# ADR-0001: Separate portable engineering repository

**Decision date:** 2026-10-08. **Status:** accepted.

## Context

Attractomancy maintains a research archive, and Attractomancy Loop is actively preparing a fixed intervention with separate hypotheses, sources, scoring and preregistration. The larger continuity program already has production organisms and neural experiments with their own source and runtime authority. Combining product development with the registered experiment risks changing tests after seeing performance and creating yet another competing Pretorius brain.

## Decision

Persona Continuity Engine is a separate repository with its own releases and acceptance tests. It is a pure conditioning compiler and future model/benchmark adapter, not a canonical memory store or cognition engine. Its initial examples are synthetic. It uses upstream ideas with explicitly pinned lineage but imports no third-party source code by default.

## Consequences

Engineering can advance independently of null Attractomancy results. The comparative benchmark must still retain factual baselines and negative findings. Any mechanism claimed to generalize must be independently tested. Integration into a production character requires an accepted adapter, migration review and separate production testing.

## Rejected alternatives

Putting the engine in Attractomancy would conflate source collection and implementation. Putting it in Attractomancy Loop would alter an active preregistered laboratory. Putting it in The Doctor Lives would overfit a general technique to Pretorius and risk contaminating the definitive production brain. Inventing a second canonical persona database would duplicate history and violate the source-of-truth boundary.
