# Project lineage and evidence map

**Date:** 2026-10-08. **Purpose:** record how PCE differs from and depends on previous work without suggesting experiments were successful when they were not.

The machine-readable pin ledger is [research/source_pins.json](../research/source_pins.json). Each source is connected to a specific immutable commit, and claims below concern design inspiration and research responsibilities, not dependency installation or validated outcomes.

**Lineage chain:** sources and hypotheses -> registered controlled experiments -> independently documented findings -> conditional engineering evaluation -> explicitly accepted downstream integration.

A useful PCE demo is **not** evidence of a continuous subjective self. The differences between frozen identity information, durable external history, learned neural change, and the sampled model utterance must remain observable. Source artifacts retain their licensing, attribution, original-language status and exact provenance.

## Change policy

When an upstream claim changes, append a dated review of the changed evidence; do not retroactively edit the original pinned snapshot. When importing a donor implementation, capture an exact commit and license, map every copied file, record local changes and rerun the recipient's tests. Initial v0.1 adopts **concepts only**, not copied donor source code.
